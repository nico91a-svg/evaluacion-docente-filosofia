# 📘 Estudio Filosofía · Evaluación Docente (Chile)

Aplicación web **gratuita y sin conexión** para preparar la *Evaluación Docente de
Conocimientos Específicos y Pedagógicos* de **Filosofía** (Educación Media), alineada
al **Temario 2026** del CPEIP.

👉 **Úsala aquí:** https://nico91a-svg.github.io/evaluacion-docente-filosofia/

## ¿Qué incluye?

- **177 preguntas con explicación**, de ellas 162 reales de las pruebas liberadas
  **2021, 2022/2023 y 2024** (con sus claves oficiales del CPEIP) + 15 nuevas de refuerzo.
- Preguntas etiquetadas por los **5 dominios** del temario:
  - **D1** Introducción a la Filosofía
  - **D2** Ontología
  - **D3** Epistemología, Ética y Política
  - **D4** Estética
  - **D5** Enseñanza-Aprendizaje (Pedagogía)

## Modos

| Modo | Para qué |
|------|----------|
| 🎯 **Práctica libre** | Eliges cuántas preguntas y de qué dominio. |
| 🧠 **Entrenamiento** | Prioriza automáticamente tus áreas más débiles. |
| ⏱️ **Simulacro** | 60 preguntas / 2 h 30 min con cronómetro, como la real. |
| 🔁 **Repaso de errores** | Solo lo que has fallado antes. |
| 📚 **Fichas** | Resúmenes por dominio con autores y conceptos clave. |
| 📊 **Progreso** | % por dominio, historial y recomendación de estudio. |
| ☁️ **Respaldo** | Exporta/importa tus datos entre computador y celular. |

## Instalar como app en el celular 📱

Abre el enlace en **Chrome (Android)** o **Safari (iPhone)** y usa el menú →
*"Agregar a pantalla de inicio"* / *"Instalar aplicación"*. Queda como una app con
ícono propio y funciona sin internet.

## Privacidad

Tus resultados se guardan **solo en tu dispositivo** (localStorage del navegador).
No hay servidor ni cuentas. Para pasar tu progreso a otro equipo, usa el modo
**Respaldo** (archivo o código de exportar/importar).

## Técnico

HTML/CSS/JS puro, sin dependencias, PWA con service worker para uso offline.
Banco de preguntas en `preguntas.js` y `preguntas_2021_2023.js` (array `window.BANCO`).
